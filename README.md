# 🏗️ SakhiConstruction Website

SakhiConstruction is a fictional construction company website built with **Django**, showcasing modern web design, blogging, and contact features.  
It serves as a professional company portfolio, blog hub, and client contact platform.

---

## 📌 Features

- 🏠 **Homepage**: Introduction to SakhiConstruction, featured posts, and services overview.  
- 📰 **Blog Section**:  
  - List of construction-related blogs.  
  - Detailed blog pages with images, descriptions, and full content.  
  - Search and pagination support.  
- 📬 **Contact Form**: Users can submit inquiries directly.  
- 🔒 **Admin Panel**: Manage blog posts, images, and user accounts.  
- 📱 **Responsive Design**: Optimized for both desktop and mobile.  

---

## 🛠️ Tech Stack

- **Backend**: [Django](https://www.djangoproject.com/) (Python)  
- **Frontend**: HTML5, CSS3, Bootstrap 5  
- **Database**: SQLite (default, can switch to PostgreSQL/MySQL)  
- **Rich Text Editing**: [django-ckeditor](https://github.com/django-ckeditor/django-ckeditor)  
- **Authentication**: Django’s built-in user system
